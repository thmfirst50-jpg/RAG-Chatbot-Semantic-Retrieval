# RAG Chatbot & Semantic Retrieval

A retrieval-augmented generation system for answering questions over private documents and structured data.

## Goal

Give an LLM relevant document context so answers are grounded in the source material.

## Design and implementation

Developed an end-to-end pipeline using recursive and contextual chunking, vector indexing, and semantic retrieval with LangChain.

## Project highlights

Added query transformation, hierarchical retrieval, and reranking to improve retrieval accuracy and reduce hallucinations.

## Technologies

- Python
- LangChain
- Vector search
- LLMs

## Repository contents

This repository currently contains the project overview. Source code, design files, test data, and project photos have not been uploaded here. The description documents the project; it is not a runnable software release.
